AI automation

N.O.V.A.

An AI-powered infrastructure assistant designed to automate operational workflows while keeping tool use controlled and intentional.

Stack: n8n, Google Gemini, Docker
Focus: Workflow automation and infrastructure operations
Repo: GitHub

Overview

N.O.V.A. explores how AI can help manage technical systems without reducing infrastructure work to opaque automation.

The project combines conversational input, workflow orchestration, and controlled execution paths so infrastructure-related tasks can be automated with clearer boundaries.

What It Shows

  • Applied AI integrated into operational tooling instead of a demo-only chatbot.
  • Workflow design that balances automation with execution control.
  • Practical thinking around system management and orchestration.

Key Work

  • Built automation workflows in n8n for infrastructure-facing tasks.
  • Integrated Google Gemini to support conversational interaction.
  • Used Docker to keep the runtime portable and easier to manage.

Next Steps

  • Expand the set of supported operational workflows.
  • Improve memory and context handling across longer sessions.
  • Refine guardrails around tool access and execution paths.
